## 복습·수정 정책 제안

초기 규칙 모듈: 다시=1분/interval0, 어려움=max(1, 이전간격×1.2)일, 기억함=max(1, 이전간격×2)일, 쉬움=max(3, 이전간격×3)일. 소수 간격은 올림. 기억함은 기존 동작과 호환. 다시/어려움은 집중 복습 대상, 성공률은 기억함/쉬움 비율로 명시한다. 평가 이벤트에 schedulerVersion을 기록하고 FSRS는 추후 교체한다.

질문·답 수정/재생성은 contentRevision 증가 및 해당 카드 일정 초기화(due=현재, interval=0). 과거 이벤트는 보존하되 이전 revision임을 구분한다. 즐겨찾기/순서 변경은 일정 유지. 카드/덱 삭제는 soft delete 후 복구기간30일 제안, 영구 삭제는 별도 확인 및 정리 작업으로 처리한다. 통계는 과거 삭제 대상 이벤트도 실제 학습 사실로 유지한다.

학습 날짜는 프로필 IANA 타임존을 기준으로 서버가 생성하고 이벤트에 고정한다. 기존 날짜는 그대로 보존한다. 타임존 변경은 이후 이벤트부터 적용하며 과거 일별 집계를 재작성하지 않는다. AI 한도 날짜는 조작 방지를 위해 서비스 공통 UTC를 사용하고 초기 UI에 리셋 시각을 현지 시각으로 표시한다.

## 비기능 요구

- 원본 로컬 데이터 삭제 금지, 마이그레이션 멱등성 및 계정 격리 필수.
- 네트워크 오류 시 입력/초안/미전송 복습을 계정별로 보존. 저장 완료와 대기 상태를 구분.
- Space 뒤집기, 1~4 평가, 좌우 탐색. 입력/textarea/select/contenteditable/조합 입력 중 단축키 미작동. 이미 평가한 카드는 탐색해도 재평가 불가.
- 모바일 터치, 키보드 포커스·dialog focus trap·라벨·대비·로딩/빈 상태/오류 재시도 검증.
- 개인 API no-store, 키/토큰/참고자료 전문 로깅 금지. AI 결과 사실 검증 보장 금지.
- 기존 테스트 통과 + 격리/이관/경합/Rules/E2E 완료가 출시 조건. 구체 성능 SLO는 실제 호스팅과 부하 측정 후 확정.
