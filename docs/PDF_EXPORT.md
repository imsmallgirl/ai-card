# 덱 PDF 내보내기

덱의 ‘PDF 내보내기’에서 카드 한 장 또는 여러 장을 고르고 출력 형식을 선택한다.

- 학습 자료형: 카드별 질문·정답·선택적 해설.
- 시험지형: 질문과 답안 작성 공간을 먼저 출력하고, 뒤쪽 별도 페이지에 정답·선택적 해설을 모은다.
- ‘PDF 저장 / 인쇄’를 누르면 새 인쇄 창이 열린다. 사용자가 브라우저 인쇄 대상에서 ‘PDF로 저장’을 선택해야 파일이 저장된다. 브라우저·OS에 따라 메뉴 이름은 다를 수 있다.

한글은 기기에 설치된 시스템 글꼴을 사용한다. 출력은 A4 기준이며 줄바꿈을 유지한다. 짧은 카드는 한 페이지에 묶고 페이지보다 긴 카드는 다음 페이지로 흐르도록 브라우저 인쇄 레이아웃을 사용한다. 카드 번호는 선택된 카드의 순서로 다시 매긴다.

자료는 현재 화면의 덱을 기준으로 내보낸다. Firestore 변경·AI 호출·서버 업로드는 없다. 팝업이 차단되면 허용 안내를 표시한다. 사용자 내용을 HTML 이스케이프하고 출력 창에서 외부 리소스와 스크립트를 차단한다. PDF 내보내기에는 개인정보와 학습 내용이 포함될 수 있으므로 사용자가 저장·공유 대상을 결정한다.

검증: 선택·순서·해설 제외·빈 선택·시험지 정답 분리·HTML 삽입 방지 테스트, 전체 테스트 168개, 타입 검사·프로덕션 빌드·번들 비밀값 검사 통과. 한글/객관식/긴 카드 샘플을 로컬 Chrome에서 PDF로 출력했다. 다른 브라우저 및 실제 모바일 저장 UI는 미검증이다. 테스트 샘플에는 운영 사용자 자료를 사용하지 않았다.
