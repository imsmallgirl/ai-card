# 이미지 자료 분석

자료로 만들기는 이제 AI 추출만 제공한다. 글 15,000자 또는 이미지 한 장, 둘을 함께 입력할 수 있다. 원본은 JPG/PNG/WebP 10MB 이하이며 브라우저에서 긴 변 1,600px 이하, JPEG 256KiB 이하로 변환한다. 파일 이름과 원본 메타데이터는 요청에 넣지 않는다. 작은 글씨가 많은 자료는 문제 영역을 잘라 올려야 한다.

Gemini generateContent v1beta의 inlineData로 전달한다. 기존 모델·Secret·하루 10회 정책과 사용량 예산을 유지한다. 이미지 입력 크기도 기존 보수적인 요청 바이트 예산에 포함된다. 고해상도·여러 페이지·PDF는 이번 범위에 없다. 서버에서 MIME/base64/용량/파일 서명을 검증하고, 이미지 없는 기존 API는 그대로 유지한다. 일반 학습 API의 64KiB 제한을 유지하고 생성 API만 450,000바이트로 제한한다.

이미지는 Firestore나 별도 파일 저장소에 보관하지 않는다. 요청 해시는 이미지까지 반영하고, 저장되는 서버 결과는 카드와 사용량뿐이다. 사용자가 동의하고 분석을 실행할 때 이미지/글이 Gemini로 전송된다. 실패 재확인을 위해 이미지와 입력을 계정별 브라우저 임시 요청에 보존하므로 로그아웃만으로 제거되지는 않는다. 요청 해제/성공 결과 수신 시 임시 요청을 제거하며 저장 성공 후 화면 자료도 지운다. GA4에는 이미지·파일명·원문을 전달하지 않는다.

검증: 이미지 스키마, 이미지 전용 Gemini 요청 본문, 자료 요청 유효성, 크기 제한, 이미지 변경 시 요청 해시 변화, 같은 ID 재시도 시 모의 Gemini 단일 호출 및 서버 기록에 이미지 미포함을 테스트한다. 실제 Gemini 호출/이미지 인식 정확도·실기기 이미지 변환은 아직 검증하지 않았다. 모델·IAM·Secret·결제·배포 변경은 수행하지 않았다.

공식 API: https://ai.google.dev/api/generate-content (Part.inlineData / Blob)
