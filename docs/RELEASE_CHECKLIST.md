# 1차 MVP 출시 체크리스트

현재 상태: 로컬 구현과 자동 검증 진행. 실제 클라우드 배포/운영 사용자 데이터 삭제/실제 Gemini 유료 호출은 실행하지 않았다. 아래 수동 항목이 남아 있으므로 전체 출시 완료로 보지 않는다.

## 배포 전

- [ ] App Hosting 또는 Vercel 배포 경로 결정. App Hosting은 Blaze/Cloud Run 등의 비용 확인
- [ ] 테스트 프로젝트/계정과 운영 프로젝트 구분, 백업/롤백 대상 확인
- [ ] SITE_URL, 운영자 이름, 실제 문의 이메일 확정
- [ ] 개인정보 안내/이용 안내의 실제 처리·보관·삭제·국외 제공/외부 제공자 정책 및 문의 절차 검토
- [ ] 삭제 상태 30일 이후 정리 담당자/주기 확정. 자동 정리 작업은 아직 없음
- [ ] AI 임시 draft의 만료 후 정리 운영 계획 수립. expiresAt은 조회 만료이며 물리 삭제 스케줄러가 아님
- [ ] 호스팅의 접속/오류 로그 보관 기간과 접근 권한 검토
- [ ] 배포 환경의 NEXT_PUBLIC_*와 서버 변수 주입, 양쪽 동기화 flag true, production mock/unlimited/emulator 제거
- [ ] 런타임 ADC 및 Firestore/Firebase Auth 사용자 조회·삭제 IAM 구성. 비밀키 Git 제외
- [ ] Firestore Rules/인덱스를 선택한 프로젝트에 배포하고 준비 상태 확인
- [ ] Firebase Google 로그인 활성화, 배포 도메인을 Authorized domains에 등록
- [ ] AI 무료 할당량/결제 상태를 모델별로 확인하고 생성 한도 설정. 실제 유료 호출 전 비용 검토
- [ ] 선택적 분석·광고는 1차 테스트에서 off 유지
- [ ] npm ci / test / typecheck / build / check:bundle / test:http / check:release 통과
- [ ] 운영 의존성 취약점 재조회: npm audit --omit=dev

## 테스트 배포 후 기능

- [ ] 로그아웃: 랜딩/로그인/정책 페이지, 비인증 API401, 개인 덱이 HTML에 없음
- [ ] Google 로그인: 팝업 차단·승인 도메인·재로그인·로그아웃, A/B 두 사용자 데이터 분리
- [ ] 자료로 만들기: 33~35·40~42번 객관식 예시, 여러 줄 보기/정답 ;, 무료 추출에 외부 AI 요청 없음
- [ ] 직접 만들기: 생성/수정/삭제, 새로고침 및 다른 기기에서 유지
- [ ] AI 자동 생성: 단어 암기 형식, 개수·목적·난이도. 실제 요청은 최소1회만, 과금 가능성을 확인한 뒤 실행
- [ ] AI 자료 추출: 덱 이름·카테고리·태그·난이도, 기존 미리보기 교체, 누락/병합 오류 거부
- [ ] 생성 X 닫기 후 초안 초기화, AI 로딩 블러는 팝업 내부만 적용
- [ ] 학습: 다음/마지막 완료 저장 후 진행률·오늘 학습량·스트릭 증가, 재방문/재시도 중복 없음
- [ ] 목표 변경: 10/20/30·직접 입력·재로그인 유지, 타임존 날짜 경계
- [ ] 네트워크 끊김/저장 공간 부족/복구, 대기 중 변경 표시 및 충돌 해결
- [ ] 테스트 계정 삭제: 재인증 취소/성공/중단 후 재시도, 데이터 삭제·다른 계정 유지·폐기 토큰 거부

## 반응형·접근성 실제 조작

아직 브라우저 자동화/화면 검증을 완료한 항목이 아니다. 코드의 CSS와 의미 구조 보완만으로 통과로 체크하지 않는다.

- [ ] 360×800 / 390×844 / 768×1024 / 1440×900: 가로 스크롤·잘림·겹침 없이 생성/미리보기/학습/완료/목표/삭제 사용
- [ ] 긴 질문·해설·덱 이름·200개 자료 카드의 스크롤 및 수정, 모바일 키보드가 저장 버튼을 가리지 않음
- [ ] 브라우저200% 확대, iOS Safari/Android Chrome, Google 로그인 팝업/복귀
- [ ] Tab/Shift+Tab 포커스 순서·링 표시, 팝업 안에 포커스 유지, 닫기 후 원래 위치 복원
- [ ] 로딩·저장 중 버튼/키보드 차단, 오류를 읽어주는 role=alert, 카드 평가 단축키가 재도입되지 않음
- [ ] 스크린리더로 질문/정답/제목/진행률/폼 라벨 확인, 색상만으로 상태를 구분하지 않음
- [ ] 실제 색 대비·Lighthouse/접근성 검사. 이번에는 점수/통과를 측정하지 않음

## 운영 첫날

- [ ] Google AI/Firestore/Auth/호스팅 비용·지연·에러 확인. 예산 알림은 자동 과금 중단과 다름
- [ ] 장애 시 AI_GENERATION_ENABLED=false와 직전 웹 배포로 롤백하는 절차 확인
- [ ] 사용자 피드백/오류 접수 창구 확인

## 삭제 상태 정리

계정 삭제는 자료를 지우기 전에 users/{uid}/account/status의 deleting=true를 설정한다. 서버 트랜잭션과 규칙이 이를 읽어 진행 중인 저장의 재생성을 차단한다. 모든 개인 하위 컬렉션을 지운 뒤 Auth 계정을 삭제한다. status에는 최소 기술 상태만 남고 cleanupAfter가 기록된다.

30일 이후, **Auth 계정 삭제가 확인되고 다른 개인 컬렉션이 남지 않았음을 확인한 상태에서만** 해당 status를 운영자가 정리한다. 삭제가 실패해 Auth 계정이 남아 있다면 잠금을 제거하지 말고 삭제를 재시도한다. 현재 자동 TTL/정리 작업은 배포하지 않았다. 다른 기기의 브라우저 로컬 자료와 제공자 백업/기본 접속 로그는 이 API로 지워지지 않는다.
