# Phase 4 진행 기록

## 작업 1 — AI 사용량·비용 보호 (2026-10-21)

계획 승인 후 첫 단위를 구현했다. UID별 일일3회/동시1개, Firestore 원자 예약·전역 시도/입장예산, request 멱등성, 결과 복구, 실패정책, 사용량UI, 관리자 비용분석 기반/API가 포함된다.

상세 변경 파일·DB·동작·제약: [AI_COST_PROTECTION.md](AI_COST_PROTECTION.md). 테스트: [TESTING.md](TESTING.md).

실제 운영 설정·배포·과금·기존 데이터 이관/삭제는 하지 않았다. 기존 학습 기능과 로컬 저장은 유지하며, 새AI생성은 Firestore ADC/IAM과 명시적 AI_GENERATION_ENABLED=true가 추가로 필요하다. 제한 저장소를 사용할 수 없으면 새provider 호출을 차단한다.

발견 문제/제약: 실 과금 금액은 계산하지 않으며 토큰 누락·unknown을 별도 표기한다. 보존7일은 논리적만료로 물리정리는 아직없다. 실제 브라우저E2E/모바일/운영자격증명은 미검증이다. 기존 auth-account의 저장방식 안내 불일치는 공통UI후속작업으로 남아 있다.

남은 작업: 동의·이벤트 기반 → 공개 덱/공유/복사/신고·관리 → 학습지속 → 광고 비활성준비 → 전체품질·출시준비. 이번 작업 후 다음 기능 구현 전에 멈춘다.

## 작업 2 — Analytics 동의·이벤트 기반 (2026-10-21)

계정별 동의/거부/철회 UI와 공개안내, 서버확정 이벤트/최초관측·7일재방문 마커, outbox·정책epoch 기반 중복/철회, 서버전용GA4 adapter·fake 테스트를 구현했다. 브라우저SDK 자동주소수집을 피하도록 초기SDK제안 대신 서버전송으로 구체화했다.

변경파일/DB/API/보관·수집의한계: [ANALYTICS.md](ANALYTICS.md). 수집/외부전송 기본false, 운영설정과실전송은하지 않았다. 기존학습·비용보호는 유지한다.

남은작업은 공개덱·공유·복사·신고/관리다. 공개·광고 이벤트는 스키마만예약했으며 실제기능과연결하지 않았다. 외부Analytics 검증·실물리삭제·브라우저E2E도 남아 있다. 이번기능 보고 후 다음단계전에멈춘다.

## 안정성 수정 — ADC 미설정 오류

Firestore SDK 초기화에서 credentials 오류가 요청 catch와 별도의 미처리 Promise로 발생하는 현상을 재현·수정했다. 사전 await 인증검사→구조화503, async repository 연결, disabled export 초기화 생략. 테스트72개/Firestore4개·타입·빌드 통과. 실제 서버 ADC 설정은 별도로 필요하며 인증/사용량 제한을 우회하지 않는다. README의 서버 인증정보 오류 해결 절을 참고한다.
